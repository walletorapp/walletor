Walletor دریافت کیے گئے ہیں جو Wallet Standard کے ذریعے طے کیے گئے ہیں اور درج ذیل جدول کے لیے دستیاب کردہ Solanas کو واضح طور پر وابستہ رکھے ہوئے ہیں۔ MetaMask Solana رجسٹر MetaMask کے سرکاری Solana کے ذریعے۔

## ایسے فیصلے

| واللٹ           | اتصال کا اضافہ ناکام ہوگیا | نوٹ                                            |
| --------------- | -------------------------- | ---------------------------------------------- |
| Phantom         | Wallet Standard            | باسر توسیع اور موبائل ہینڈوف کی حمایت کرتا ہے۔ |
| Backpack        | Wallet Standard            | باسر توسیع اور موبائل ہینڈوف کی حمایت کرتا ہے۔ |
| Trust Wallet    | Wallet Standard            | غیر متصل                                       |
| MetaMask Solana | MetaMask Solana اتصال      | MetaMask ورژن Solana کے ساتھ درکار ہے          |

واللیٹ کی دستیابی کا انحصار براؤزر، ڈیوائس، توسیعی تنصیبات اور انفنٹری ورژن پر ہوتا ہے۔ ایک **غیر متصل** لیبل کا مطلب یہ ہے کہ کرنٹ نصب کیا گیا ہے اور موجودہ براؤزر میں دستیاب ہے۔ ایک غیر آئینی مشین کا انتخاب کرنے سے اپنی سرکاری تنصیبات کا آغاز ہوتا ہے جس میں سے ایک کی مدد کرتا ہے ۔

## اتصال مدون نہیں ہوسکتا

اِس ویب‌سائٹ پر ایک عوامی ویب‌سائٹ کا پتہ چلتا ہے ۔ ہر شوپ کو اب بھی الگ الگ دستخط کی ضرورت ہوتی ہے۔ Walletor سے مراد بیج کی اصطلاحات یا نجی کلیدوں کی درخواست نہیں ہوتی۔

## موبائل فون

Walletor رجسٹرس Solana Mobile Wallet Standard اتنی مطابقت انگیز اینڈروئیڈ انفنٹریز سے رابطہ حاصل کیا جا سکتا ہے۔ دوسرے موبائل اوزاروں پر، Walletor کے اندر جب دستیاب ہوتا ہے تو Walletor پر دستخط کرنے اور تصدیق شدہ سزائے موت کا انتظار کرنے کے بعد واپس آگیا۔

## اگر آپ کا کمپیوٹر دکھائی نہیں دیتا

1. حسابِ ابجد کی تصدیق Solana بنیادی نیٹ کی معاونت کرتی ہے۔
2. جمع کرنا یا توسیع کرنا۔
3. اتصال مدون کرنے سے پہلے فائل کو عکس بند کریں.
4. ہمت Walletor اور دوبارہ کوشش.
5. فرق فرق فرق فرق فرقوں کو عارضی طور پر استعمال کریں اگر کئی ایک ہی فراہم کِیا جائے تو

:::danger
Walletor حمایت کبھی آپ کی بیج کی اصطلاح، نجی کلید یا دور تک رسائی کے لیے آپ کے ڈیوائس سے نہیں مانگے گا۔
:::
