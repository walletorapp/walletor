## Software interface only

Walletor is a non-custodial software interface for requesting decentralized Solana swap routes. Walletor does not hold a trader's seed phrase or private key, make investment decisions for the trader, guarantee execution, reverse confirmed transactions, or recover assets sent to the wrong address.

Every swap requires approval in the connected wallet. You remain responsible for reviewing the token mints, transaction instructions, quoted output, price impact, minimum received, fees, and destination before signing.

## No guarantee of access or execution

Quotes, token metadata, balances, routes, estimated values, confirmation times, and interface availability can be delayed, incomplete, unavailable, or changed before execution. Displaying a token does not mean that it is safe, liquid, legitimate, or tradable. Jupiter's executable order response—not a search result—is Walletor's source of truth for current route availability.

Walletor may restrict, suspend, or discontinue features to address security, legal, technical, abuse, or third-party-service concerns.

## Fees

The active quote and wallet approval are the source of truth for fees. Walletor currently requests a **50 basis point (0.50%) total referral fee** on supported fee-bearing Jupiter orders. Jupiter's current referral arrangement allocates 20% of that fee to Jupiter and 80% to Walletor's partner share. Network, priority, execution, token-account, and wallet costs can be separate.

Examples in these docs are illustrations, not guaranteed executed amounts. Read [Fees & quotes](/swaps/fees-and-quotes/) for the current published configuration.

## WLT Points and Prize Pool

WLT Points are off-chain promotional accounting points for a possible future allocation. They are not currently transferable tokens, money, stored value, equity, debt, a deposit, a claim against Walletor, or a promise of an airdrop. Walletor has not published a conversion rate, token launch date, redemption right, or guaranteed monetary value.

Prize Pool eligibility, activity weight, an estimated allocation, or a displayed balance does not guarantee winnings or payment. Mainnet-USDC withdrawals are available only for a verified entitlement in an active, funded distribution. Walletor may correct objectively erroneous or duplicated ledger entries through auditable reversing records.

When a distribution is activated, Walletor withholds a 250 basis point (2.50%) claim fee from each gross allocation before funding the net USDC claim. The winner separately pays the Solana network and any token-account creation cost shown by the wallet.

## Security and scams

Never share a seed phrase, private key, recovery phrase, or secret key with Walletor or anyone claiming to provide Walletor support. Walletor support will not ask you to transfer assets to unlock a reward. Verify that you are using `walletor.com` or `www.docs.walletor.com` before connecting a wallet.
