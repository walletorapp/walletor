Penemuan Token bukan dukungan. Siapapun dapat membuat token Solana, menyalin nama, menggunakan kembali gambar, atau mempublikasikan metadata menyesatkan.

## Verifikasi mint

Alamat mint adalah identifikasi token primer. Bandingkan dengan saluran resmi proyek dan periksa secara independen pada Solscan sebelum perdagangan.

## Memahami label

**Verifikasi** berarti token cocok dengan data verifikasi yang disediakan oleh Walletor apos; s normal sumber metadata. Ini tidak menjamin stabilitas harga, likuiditas, legitimasi, atau keselamatan.

**Belum diverifikasi** berarti Anda harus melakukan pemeriksaan tambahan. Ini tidak berarti secara otomatis token berbahaya.

**Tidak ada rute** berarti Jupiter tidak mengembalikan perintah executable untuk pasangan dan jumlah yang dipilih pada saat itu.

## Periksa sebelum menandai

- Alamat mint dan tanda desimal
- Token otoritas dan ekstensi akun
- Kualitas likuiditas dan rute
- Tabrakan harga dan minimum diterima
- Apakah transaksi dompet berisi instruksi tak terduga

## Logo bisa salah

Logo resolusi tinggi masih tak dipercaya. Walletor perlakukan semua URL image remote sebagai tidak terpercaya dan gunakan fallback ketika mereka gagal.

:::danger
Jangan pernah menandatangani transaksi Anda tidak mengerti. Koneksi dompet dapat dikembalikan; transaksi berantai yang ditanda tangani mungkin tidak.
:::

Terjemahan ini disediakan untuk kemudahan. Jika terdapat perbedaan dengan versi bahasa Inggris, versi bahasa Inggris merupakan sumber resmi.
:::
