---

Walletor discovers install Solana walets through the Wallet Standard and keeps eksplisit connection or install options available for the wallet listed below. MetaMask Solana register melalui MetaMask resmi Solana konektor.

## Opsi yang didukung

| Dompet          | Metode koneksi          | Catatan                                                        |
| --------------- | ----------------------- | -------------------------------------------------------------- |
| Phantom         | Wallet Standard         | Ekstensi peramban dan handoff mobile yang didukung             |
| Backpack        | Wallet Standard         | Ekstensi peramban dan handoff mobile yang didukung             |
| Trust Wallet    | Wallet Standard         | Ketersediaan bergantung pada platform dan versi yang terpasang |
| MetaMask Solana | Koneksi MetaMask Solana | Membutuhkan versi MetaMask dengan dukungan Solana              |

Ketersediaan dompet tergantung pada peramban, perangkat, instalasi ekstensi, dan versi dompet. Label **Terdeteksi** berarti dompet terpasang dan tersedia dalam peramban saat ini. Memilih dompet yang tidak tersedia membuka aliran instalasi resminya di mana adaptor dompet mendukungnya.

## Koneksi bukan persetujuan transaksi

Menghubungkan alamat dompet publik dengan situs. Setiap pertukaran masih membutuhkan tanda tangan dompet terpisah. Walletor tidak meminta atau menyimpan frasa benih atau kunci privat.

## Dompet seluler

Walletor register Solana Mobile Wallet Standard sehingga kompatibel dompet Android dapat menerima sambungan handoff. Pada perangkat seluler lainnya, buka Walletor di dalam peramban aplikasi dompet saat tersedia. Kembali ke Walletor setelah menandatangani dan menunggu tanda terima eksekusi dikonfirmasi.

## Jika dompet Anda tidak muncul

1. Konfirmasi dukungan dompet Solana Mainnet.
2. Update aplikasi dompet atau ekstensi.
3. Buka dompet sebelum membuka daftar sambungan.
4. Segarkan Walletor dan coba lagi.
5. Nonaktifkan ekstensi dompet konflik sementara jika beberapa menyuntikkan penyedia yang sama.

:::danger
Dukungan Walletor tidak akan pernah meminta frasa benih Anda, kunci privat, atau remote-control akses ke perangkat Anda.
:::

:::
