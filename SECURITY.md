# Security reporting

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/walletorapp/walletor/security/advisories/new).
Avoid posting credentials, wallet private keys, personal records or exploit details
in public issues.

This repository contains a public source snapshot and example configuration.
Reports should identify the affected file and commit and provide a minimal
reproduction using local or disposable test resources.

Do not submit transactions, move funds or test against other users' wallets when
investigating a suspected issue. A report does not require access to production
secrets or a funded wallet.
